Import DAT catalogs a folder (or single file) of .dat / .xml / .zip / .gz

System and source are read from each DAT's header and filename. ScummVM engine DATs attach verification hashes to your existing ScummVM entries instead of creating duplicates. Unrecognized DATs (arcade sets, artwork packs, BIOS images…) are skipped and listed below.

Scan ROM files hash downloaded files and match them to the catalog

Step 1 of 2: scanning identifies what you have — every file is hashed (CRC/MD5/SHA1) and matched against the DAT catalogs, including ROMs inside zip archives. Anything unmatched is automatically cataloged as a local entry (system from folder name or extension) so nothing is lost. Files stay where they are. Step 2 — organizing them onto your SD card — is the next card below.

Organize & export to SD card step 2 — copy matched files into <dest>\<system>\ folders

Only: (0 = off)
Platforms Leave out:

Copies the ticked platforms into <dest>\<system>\ under the folder names ES-DE knows (psx, gc, n3ds…), only files the system can launch; .7z/.rar (and disc games in a .zip) are unpacked, and a multi-file disc becomes one entry. gamelist.xml gives ES-DE each game's name, rating and genre. Best-rated games go first (your rating or the crowd's score). Nothing is moved or deleted; files already on the card are skipped, so re-running tops up. An export that would not fit is refused before anything is written, and a card is never filled past its last 1 GB (or 1%).

Library upkeep RomCom keeps the library tidy by itself — this is what it does, and a button to do it now

Artwork box art, snaps, title screens and arcade marquees, for the games you have

Arcade sets come from ArcadeDB by their set name (flyer, in-game snap, marquee); everything else from libretro-thumbnails, matched by name — the exact libretro spelling, then the same title without its region and revision tags. Images are cached on this PC and shared by every card; the export's artwork for ES-DE box copies them beside the games. In ES-DE, set Other settings → Game media directory to <card>\ES-DE\downloaded_media.
